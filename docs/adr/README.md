# Architecture Decision Records

Architecture Decision Records (ADRs) capture durable, consequential choices and
the evidence and trade-offs behind them. They are not required for routine
implementation details.

Use the next four-digit sequence number and a short kebab-case filename. Once
accepted, preserve the original decision record; supersede it with a new ADR
rather than rewriting history.

```markdown
# ADR NNNN — Title

Status:
Date:

## Context

## Decision

## Alternatives Considered

## Consequences
```
