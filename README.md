# Embyr

Embyr is a curiosity-driven learning app where the things you discover,
understand, practise, and create grow into a living personal world.

Kanopi is Embyr's AI companion.

**Project status:** Pre-implementation / architecture frozen, engineering
foundation in progress.

Android will be developed first. The current technology direction is:

- Kotlin and Jetpack Compose for Android
- Python and FastAPI for the backend
- PostgreSQL and pgvector for persistence and semantic retrieval

Product and architecture documentation lives under [`docs/product`](docs/product/)
and [`docs/architecture`](docs/architecture/). See
[`CONTRIBUTING.md`](CONTRIBUTING.md) before starting work.
